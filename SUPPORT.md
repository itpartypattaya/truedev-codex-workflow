# Support

Use [GitHub Issues](https://github.com/itpartypattaya/truedev-codex-workflow/issues) for installation
problems, reproducible workflow defects, portability reports, and documentation questions.

Include:

- the plugin version and Codex version;
- operating system and Python version;
- whether the plugin and hooks are enabled and trusted;
- the workflow command or hook event that failed;
- a minimal reproduction with secrets, personal data, repository contents, and transcripts removed.

For a suspected vulnerability, do not open a public issue containing exploit details or sensitive
data. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

Support is best-effort. Requests for project-specific implementation, legal approval, production
access, or recovery of deleted user data are outside the plugin's support scope.
